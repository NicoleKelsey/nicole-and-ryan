Put your photographs in this folder, then reference them in js/config.js, e.g.
  images: { hero: "assets/images/hero.jpg" }
  gallery.items: { src: "assets/images/engagement-1.jpg", alt: "Nicole and Ryan at ...", caption: "..." }

Tips: JPG, max ~1920px on the long side, under ~400 KB each (use squoosh.app to compress).
Avoid spaces in file names. Any image that is missing shows an elegant placeholder instead.
